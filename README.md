# Inter Desktop

Windows 11の仮想デスクトップと、開いているウィンドウを管理するTauriアプリです。UIにはAdobe Spectrum 2を使っています。

## アーキテクチャ

```text
React + Spectrum 2
       │ Tauri invoke（アプリ内IPC）
       ▼
Rust command layer
       ├─ winvd: 仮想デスクトップの取得・切替・作成・削除・名前変更・ウィンドウ移動/固定
       └─ windows crate: EnumWindowsによる表示中ウィンドウの列挙
```

別プロセスのHTTPサーバーは使わず、Rustがアプリ内でWindows APIを呼び出します。デスクトップの識別子は`winvd`の抽象化に任せ、アプリ側でUUIDを読んだり保存したりしません。画面は約2.5秒ごとに状態を読み直します。

## 現在の機能

- 仮想デスクトップの一覧、切替、作成、名前変更、削除
- ウィンドウの一覧、検索、アプリ/デスクトップでの絞り込み、最小化ウィンドウの除外
- ウィンドウ行をサイドバーのデスクトップへドラッグして移動
- 行の操作メニューまたは右クリックから、デスクトップ移動、全デスクトップへの固定/解除、ウィンドウを閉じる
- ライト/ダークテーマ切替（端末内に保存）

デスクトップやウィンドウの選択条件の保存/復元、デスクトップ自体のドラッグ並べ替え、自動復元はまだ含みません。`winvd` 0.0.49の公開APIにデスクトップの並べ替え操作がないため、並べ替えは別途APIの選定が必要です。

## 動作要件

`winvd` 0.0.49が必要とするWindows 11 24H2（build 26100.2605）以降が必要です。未対応環境では画面にAPIエラーを表示します。

## 開発

```powershell
pnpm install
pnpm tauri dev
```
